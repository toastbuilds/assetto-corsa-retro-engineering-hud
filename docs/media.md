# Retro UI video gallery

All 38 clips are included in this repository. Open an MP4 link to view the clip in GitHub or download it.

These eight-second, silent H.264 clips run at 1080p/60 FPS. They render the actual Lua UI with deterministic simulated telemetry; they are not footage captured while driving. The digital Dial clip was regenerated after the ABS fix in 2.5.1.
