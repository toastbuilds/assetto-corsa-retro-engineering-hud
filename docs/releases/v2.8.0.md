# Retro UI 2.8.0

New Dash layouts, clearer race info, and fixes to the Timer and GT7 gauges.

- **Dash:** a new horizontal dashboard with two layouts.
- **GT7:** 16 mini-gauge styles, plus a slipstream glow that follows the car ahead.
- **Race Notices:** overtake recaps with rival incidents; turn on the four-lap gap graph if you want more detail.
- **Driving cues:** suggested corner gear and pedal traces that show input alongside estimated output, including TC/ABS.
- **Leaderboard:** session time and lap progress are easier to scan; online connection bars are clearer, estimates show `~`, and air/track temperatures are gone.
- **Timer:** timed races now catch the last lap. The clock stays centered, and sector/delta text keeps a steady size.
- **Personalization:** set a theme and color palette for each app.
- **Polish:** smoother GT7 lighting and needles, clearer fuel warnings and redline marks.
