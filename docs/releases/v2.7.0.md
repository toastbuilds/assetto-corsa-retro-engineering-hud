# Retro UI 2.7.0

Retro UI 2.7.0 adds a new family of analog and digital gauges, animated gear selectors, and class-rival pace notices.

## New dial designs

- Standalone analog dials add Jewel 1A, Spectrum 2A, Track 3A, Halo 6A and Snap Selector.
- Standalone digital dials add Jewel 1D, Spectrum 2D, Core Capsule 5D, Halo 6D, Floating 4D, Orbit and Snap Selector.
- Snap Selector moves the gear positions around a center selector and snaps to the selected gear. Shift cues highlight the next gear in red above the configured redline threshold by 2%, and the previous gear in blue at or below 55% RPM. GT7 RPM dials also offer Snap Selector.
- GT7 auxiliary gauges add Halo, Jewel and Spectrum treatments.

## Race notices

Class-rival pace alerts are now part of Race Notices; the separate Battle Panel is removed. Rear notices report a closing threat from the class rival behind. A green attack opportunity appears for the class rival ahead when gaining at least 0.5 seconds per lap with a predicted catch under four laps. Attack and rear alerts can be enabled independently.

## Refinements

- The original standalone dial now fades its backlight using the same eased transition as GT7.
- Refined redline marks, gear selector alignment, dial spacing and readout positions across analog and digital designs.
- GT7 Jewel RPM limiter strokes keep a visible gap around the crown dots.
- New dial faces preserve the bezel indicators, status icons, selected theme and existing telemetry features.

## Install

Download **RetroUI-v2.7.0.zip**, drag it into Content Manager, install and enable Retro UI. Existing `apps/lua/RetroUI` installations and saved settings are retained. Manual installation extracts the ZIP into the Assetto Corsa folder.

Retro UI remains free with every feature included. See the [user guide](../user-guide.md), [settings reference](../settings.md) and [full changelog](../../CHANGELOG.md).
