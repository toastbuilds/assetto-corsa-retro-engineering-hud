# Retro UI 2.5.1

Retro UI is now distributed as **one free, complete app**. Every GT7 layout, component editor, needle style and Laps animation is included. Optional donations will support development without unlocking features.

## Fixes

- Digital Dial reads the ABS level independently from TC.
- Leaderboard gaps use CSP timing when available, continuous position history and a clearly marked `~` distance/speed fallback.
- Finish-line timing stays continuous when an online rival's lap counter remains at zero.

## Install or update

Download **RetroUI-v2.5.1.zip**, drag it into Content Manager, enable Retro UI and open the desired windows from the CSP app sidebar. Manual installation uses `apps/lua/RetroUI` inside Assetto Corsa.

The app identity and existing settings are retained. Back up customized Relative/Leaderboard `classes.ini` files before ZIP installation and restore them afterward. The optional repository installer preserves those files automatically.

CSP 0.2.8 or newer is recommended for complete window anchoring and mouse pass-through. Car-specific readings depend on available telemetry.

## Package and documentation

The compact ZIP contains runtime files, two notification sounds, class maps, a user guide, settings reference, changelog and licenses. Concept images and footage are excluded. A SHA-256 checksum is attached.
