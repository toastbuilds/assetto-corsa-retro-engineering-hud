# Retro UI 2.6.0

Retro UI 2.6.0 brings a fresh set of instrument designs and clearer timing displays to Assetto Corsa.

## New instrument styles

- Choose from four new analog Dial layouts: Concentric, Fan, Shelf and Spoke. Each comes in light and dark finishes.
- Five digital Dial variants add new ways to arrange the readouts, steering details and perimeter gauges.
- GT7 side dials now use compositions that match the selected instrument style, with hybrid readouts and lower auxiliary arcs.
- Settings give you more control over variants, indicators and visual details.

## Timing and readability

- Timer results and deltas sit more clearly around the clock, with steady sizing and a full-width final-lap banner.
- Final-lap detection also reads Assetto Corsa's native signal. Results flash for two seconds.
- Approaching FAST rows blink while keeping their text readable.
- Analog redline blocks and GT7 limiter animation are easier to read.
- Lap row fades keep their original colors.

## Install

Download **RetroUI-v2.6.0.zip**, drag it into Content Manager, install and enable Retro UI. Your existing `apps/lua/RetroUI` installation and saved settings are retained. Manual installation extracts the ZIP into the Assetto Corsa folder.

Retro UI remains free with every feature included. See the [OverTake.gg description](../overtake-description.md) for the player-facing feature overview.
